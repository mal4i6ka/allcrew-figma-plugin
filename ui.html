          1 · Run the bridge
        
    
        
        
    
          
    
          
        
    
        
    One Node script, nothing to install — it ships inside this plugin, so it always matches. Save it anywhere and run it; the command above assumes your browser's Downloads folder. Needs Node 18+, which the CLI agent you're wiring up already requires.
    
        
    It mints a secret of its own into ~/.altery/agent-secret and opens a five-minute pairing window — press Pair with bridge above and this plugin picks it up. Nothing to type, nothing shared between machines, no secret in the plugin.

It regenerates from the live op list, so re-copy after a plugin update.
