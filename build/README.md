# Altery Design System Export — установка плагина

Готовый к запуску Figma-плагин: экспортирует локальные переменные файла
(design tokens) в CSS / JSON / TypeScript. Собран заранее — билд не нужен,
достаточно импортировать манифест.

## Содержимое архива

```
manifest.json     — манифест плагина (main: dist/code.js, ui: dist/ui.html)
dist/code.js      — собранный код плагина (main thread)
dist/ui.html      — собранный UI плагина (iframe)
README.md         — этот файл
```

Все три файла обязательны и должны оставаться **в этой же относительной
структуре** (`manifest.json` рядом с папкой `dist/`) — манифест ссылается на
`dist/code.js` и `dist/ui.html` относительными путями.

---

## Установка — для человека

1. Распакуй архив в любую папку на диске (важно сохранить структуру —
   `manifest.json` и `dist/` должны лежать рядом).
2. Открой **Figma Desktop** (в браузерной версии импорт по манифесту
   недоступен).
3. Меню **Menu → Plugins → Development → Import plugin from manifest…**
   (если пункта "Development" нет — включи Developer mode в настройках
   аккаунта Figma).
4. Выбери файл `manifest.json` из распакованной папки.
5. Плагин появится в **Plugins → Development → Altery Design System Export**.
6. Открой Figma-файл с нужными переменными/коллекциями и запусти плагин —
   он сразу сканирует документ и показывает сводку. Настройки экспорта —
   через шестерёнку в шапке плагина.

Билд не требуется: `dist/code.js` и `dist/ui.html` уже собраны и готовы
к работе как есть.

## Установка — для агента

Инструкции для автоматизированного агента (Claude Code, скрипт CI и т.п.),
который должен подключить плагин к Figma без участия человека там, где это
возможно, и подготовить всё для шага, который человек обязан выполнить сам.

**Важно:** сам финальный шаг импорта манифеста в Figma Desktop — это
действие в GUI десктоп-приложения, у Figma нет CLI/API для программной
установки dev-плагинов. Агент может подготовить окружение и провалидировать
пакет, но нажать *Import plugin from manifest…* обязан человек.

Что агент может сделать сам:

1. Распаковать архив в целевую директорию, например:
   ```bash
   unzip altery-figma-ds-plugin.zip -d ~/figma-plugins/altery-design-system-export
   ```
2. Провалидировать целостность пакета перед тем как просить человека
   импортировать его:
   ```bash
   cd ~/figma-plugins/altery-design-system-export
   test -f manifest.json && test -f dist/code.js && test -f dist/ui.html && echo OK
   python3 -c "import json,sys; m=json.load(open('manifest.json')); \
     assert m['main']=='dist/code.js' and m['ui']=='dist/ui.html'; print('manifest OK')"
   ```
3. Проверить, что пути в манифесте (`main`, `ui`) действительно указывают на
   существующие файлы относительно `manifest.json` — если пакет собирался
   заново из исходников, а не брался из этого архива, поля могут разъехаться.
4. Если нужно пересобрать из исходников (`src/`) вместо использования
   готового `dist/` из архива:
   ```bash
   npm install
   npm run build   # запускает build.mjs, обновляет dist/code.js и dist/ui.html
   ```
5. После распаковки/сборки — сообщить человеку абсолютный путь к
   `manifest.json` и попросить выполнить шаг 3–4 из раздела «для человека»
   (Import plugin from manifest…), так как это единственный шаг, требующий
   GUI Figma Desktop.

Плагин **не требует сети** для основной функции (чтение переменных и генерация
пакета — целиком на стороне клиента через Figma Plugin API); опциональный шаг
доставки пакета POST-ом на пользовательский receiver-эндпоинт настраивается
внутри UI плагина и не входит в установку.
